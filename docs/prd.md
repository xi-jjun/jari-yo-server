# (내 맘대로) Product Requirements Document
## Overview
식당/카페/스터디룸 등, '가게'의 좌석을 예약하고, '현재 남은 좌석'정보를 조회할 수 있는 서비스를 만들고자 함.

해결하고자 했던 것
1. 카페에 사람이 많은줄 모르고 공부하러 갔을 때, 비참하게 돌아와야하는 슬픔
2. 커플끼리 두 자리가 있는 테이블을 가고 싶었으나 떨어진 자리로만 존재할 때
3. 회사에서 점심 먹으러 갈 때, 사람이 적은 곳으로 빠르게 가고 싶을 때

만들고 싶은 것
- 식당, 카페 등에 좌석 예약 시스템 개발
- 유저는 자리에 있는 QR코드를 찍으면 자리 차지한 것으로 간주
- 점주들은 가게의 위치 및 좌석 수 세팅 필요
- 지도에서 해당 가게에 대한 잔여 좌석 수 확인 가능해야함
- 앞으로 생길 좌석 수도 확인되면 좋을 듯

## Goal
- 이 프로젝트의 목적은 개발 공부를 위해 가상의 서비스를 만드는 것입니다.
- 이루고자 하는 목적
  - 한번도 경험하지 못한 MSA로의 구성
  - Spring boot Kotlin을 활용한 멀티모듈 구조 구현
  - 나에게 익숙한 layered architecture 로 시작하여, 리팩터링을 통해 하나씩 적용해나가는 경험 습득

## Requirements
### 1. 회원 관리 시스템
- 로그인 기능
  - JWT 인증
  - OAuth2 는 고려 X
  - 계정 생성 시 이메일 인증 고려 X
- 내 정보 수정이 가능해야 함
  - ID는 수정 불가
- 자영업자와 유저의 개념은 분리되어야 함
- 어드민과 일반 사용자(자영업자/유저)의 개념 또한 분리되어야 함

### 2. 유저 좌석 관리 기능
- 유저가 좌석의 QR코드를 찍으면 '좌석 선점'이 됨.
  - 이미 선점된 좌석은 다른 사람이 예약하거나, 선점할 수 없음
  - 좌석 선점은 특정 기간만큼 유효 (가게 정책에 따른 값)
- 좌석을 선점한 유저가 다시 QR코드를 찍으면 '좌석 해제'가 됨.
- 유저는 좌석을 '예약'할 수 있음.
  - 이미 선점된 좌석은 예약할 수 없음
  - 온라인 선점 가능한 좌석만 예약할 수 있음.
  - 예약 후 일정 시간 내 도착하지 못하면 예약이 취소됨. (가게 정책에 따른 값)
- 유저는 선점된 좌석에 대해, '좌석 대기'를 신청할 수 있음
  - 1개의 좌석에 대해, 대기 인원은 최대 3명까지 가능 (시스템 정책)
  - 기 사용자가 '좌석 해제'를 하면, 가장 먼저 대기 신청을 한 유저가 '우선 좌석 선점권'을 획득

### 3. 자영업자 가게 관리 기능
- 자영업자는 가게의 일반 정보를 세팅할 수 있음
  - 가게의 지도상 위치를 세팅 가능
  - 가게 이름 등의 기본 정보 세팅 가능
- 자영업자는 가게의 좌석 관련 메타 정보를 설정 할 수 있음
  - 온라인/오프라인 선점 가능 여부를 좌석마다 세팅 가능
  - 좌석 배치도 세팅 가능
  - 좌석 최대 선점 가능 시간 설정 가능
  - 예약 후 도착 제한 시간 설정 가능
  - QR 코드 생성 가능

### 4. 알림 시스템
- 예약이 성공하면 유저에게 알림이 전송되어야 함.
- 예약이 취소되면 유저에게 알림이 전송되어야 함.
- 자리가 선점되면 유저에게 알림이 전송되어야 함.
- 자리가 선점 해제되면 유저에게 알림이 전송되어야 함.
- 좌석 대기 중인 좌석이 선점가능해질 때, 알림이 전송되어야 함.
