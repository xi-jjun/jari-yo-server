## 1. 구현 시작 전
### 구현해야할 기능
- 로그인 기능
  - JWT 인증
  - OAuth2 는 고려 X
  - 계정 생성 시 이메일 인증 고려 X
- 내 정보 수정이 가능해야 함
  - ID는 수정 불가
- 자영업자와 유저의 개념은 분리되어야 함
- 어드민과 일반 사용자(자영업자/유저)의 개념 또한 분리되어야 함

### 구현 방식

- TDD X (써본적 없음)
